# Career Radar

Mobile-first MVP for a career decision layer that helps experienced professionals decide which opportunities are worth their limited attention.

## Product premise

Career Radar is **not another job board**. The goal is to reduce search time, decision cost, and career risk by surfacing a small, explainable weekly set of opportunities.

## Tester MVP

The current v0 focuses on:

- Weekly recommendation cards
- Priority vs watchlist framing
- Why the role matters
- Scope and risk summary
- Direct job link
- Apply / Hold / Skip feedback
- Minimal career profile
- Mobile-first interaction

## Current limitations

- Tester decisions are stored in browser localStorage only
- No authentication yet
- No central sync yet
- No secure resume upload yet
- Demo job data is currently hard-coded

## Near-term roadmap

1. Central tester identity and data sync
2. Secure resume upload
3. Per-tester recommendation data
4. Learned preference rules from user feedback
5. Admin/backend integration with the existing Job Search Target Company Map

## Deployment

This repository is intentionally static-first so it can be deployed with GitHub Pages for the first 3–5 testers.
